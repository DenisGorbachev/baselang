Note that modern physics doesn't define "present". It assumes that the time is continuous, which means that every interval between "past" and "future" contains infinitely many time-points. Whether this is correct or not is beyond the scope of this article. Here, we only assume the existence of a previous point (past) and a next point (future).

---

The distinction between "past" and "future" gives us a notion of inequality.

---

First, the previous states are not fully observable. The root problem is that observations take time, during which the states change. This is helped by the fact that some changes take more time than observations. Yet, with only some observations done in time, the past is incomplete.

First, the model does not fully describe reality. The root problem is that models rely on observations, which themselves are imperfect. This is helped by the fact that we accumulate observations over time. Yet, with a fixed set of observations, the model is incomplete.

Third, the next states can't be calculated perfectly. The root problem is that calculations take time, during which the state changes. This is helped by the fact that we can approximate the next states during the allocated time. Yet, with a fixed deadline, the future is imperfect.
